A deadpan weather forecast for Blorthaven, a city that does not exist on Tuesdays.

> In Blorthaven, expect 14 degrees and light rain from 4pm, though the city will not be there on Tuesdays, so plan accordingly.

Run `python3 main.py` — it prints the forecast and writes it to `/output/entry.txt`.
